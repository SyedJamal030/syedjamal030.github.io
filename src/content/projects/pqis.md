## The Technical Challenge
PQIS competes directly with global compliance giants like SGS, but their digital footprint didn't reflect their enterprise authority. The company's original web presence was a cluttered, messy, single-page legacy site hosted on an unoptimized Oracle APEX instance. It suffered from fragmented navigation, slow response times, and poor mobile scalability.

As the **Lead Frontend Engineer**, my mission was to execute a total frontend overhaul: refactoring the chaotic legacy layout into a highly authoritative, structured B2B multi-page platform, while migrating the stack to a modern, lightning-fast architecture.

## Key Contributions

### 1. Legacy Code Refactoring & Modernization
Rescued the brand from an outdated, unmaintainable Oracle-hosted setup. Completely re-engineered the content hierarchy from scratch, transforming a messy single page into a polished, multi-page corporate ecosystem with strict attention to semantic layout.

### 2. Bespoke Interactive SVG MapViewer
Engineered a custom, dark-themed regional compliance map (<a href="https://pqis.com.pk/#map" target="_blank" rel="noopener noreferrer" class="text-primary underline font-medium">"Core Coverage Footprint"</a>) entirely from scratch using optimized vector paths. Implemented asynchronous state logic where selecting an operational node instantly zooms, dynamically repositions, and highlights targeted geographical matrices (e.g., Karachi) with hardware-accelerated fluid transitions and a clean "Reset Map View" flow.

### 3. Performance-First Architecture (Astro SSG)
Leveraged Astro to replace the sluggish legacy framework with a content-first static architecture. By ensuring zero client-side JavaScript overhead by default, I eliminated previous loading bottlenecks, maximized user retention, and secured an elite technical foundation for local and global SEO.

### 4. Component-Driven UI Engineering
Translated an industrial, premium brand identity into modular code using **Tailwind CSS** and **DaisyUI**. Engineered crisp, fully responsive layouts for core service frameworks ("Inspection & Audits", "DMAIC Specialization") that load flawlessly across all device spectrums.

### 5. Future-Proof CMS Architecture
Intentionally structured the new directory schemes and data layers to support a plug-and-play migration to a git-backed headless content system (such as Sveltia CMS). This ensures non-technical admins can scale service descriptions in the future without touching a single line of code.
